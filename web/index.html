05 / CONTEXT AND BEHAVIOR TOGETHER

Do the two kinds of disadvantage go together?

How records with each context factor count (columns) split across behavior factor counts (rows).

Each column sums to 100%: darker cells hold a larger share of that column’s records. Column sample sizes (n) sit above the grid; hover or focus a cell for its count. These are exploratory counts, not validated scales; the pattern is an association and says nothing about causes or personal responsibility.

Methodology & data definitions

Context factors · 0–4

One point each: no home internet; travel time above 30 minutes (code ≥3); mother's education below secondary (Medu <3); father's education below secondary (Fedu <3).

Behavior factors · 0–4

One point each: study time below 2 hours/week; workday alcohol code ≥3; weekend alcohol code ≥3; no stated desire for higher education. These thresholds are project choices, not UCI definitions.

Records, not unique students

395 mathematics + 649 Portuguese course records. Some students appear in both subjects. Combined means weight every course record equally; use the subject filter for separate comparisons. Grades run from 0 to 20, with ≥10 treated as passing.

All plots include zero grades. Small groups can yield unstable averages. Parental education: 0 none, 1 primary, 2 grades 5–9, 3 secondary, 4 higher. Travel: 1 <15 min, 2 15–30 min, 3 30–60 min, 4 >60 min.
